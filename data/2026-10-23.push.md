# AI 日报 · 10月23日 周五

**🔥 头条**
1. **OpenAI 正式发布 Decisions API：面向分类、路由、评分等小决策，最高快 10 倍** — OpenAI 宣布基于 GPT-6 Luna 的 Decisions API 正式可用，面向分类、路由、评分等有界答案问题；官方称其速度最高比通过 Responses API 使用 GPT-6 Luna 快 10x，定位低延迟、低成本的小决策场景。
2. **Canva 发布首款自研图像生成模型，面向所有用户开放** — Canva 推出其首个图像生成模型并面向所有用户开放，承诺更好的性能与更可定制的生成效果；The Verge 称该模型会“先规划设计再生成”，强调设计流程可控性。
3. **Microsoft AI 发布 SDBench 与 MAI-DxO 诊断系统，论文登上 Science** — Microsoft AI 发布 Sequential Diagnosis Benchmark（SDBench）和 AI 诊断系统 MAI-DxO，相关论文发表于 Science；TechCrunch 称该系统在困难病例上击败全科医生，Mustafa Suleyman 正以此推进“医疗超级智能”。

**🧠 模型 & 产品**
- **Claude 网页、桌面和移动端将默认启用 auto mode** — Claude 官方宣布，下周起 Pro、Max 和 Team 套餐在网页、桌面和移动端应用中的会话将默认以 auto mode 运行；该模式不再逐步请求用户批准，而是由自动检查拦截高风险操作。
- **1Password 推出 for Agents：让 AI 智能体代为登录但不接触密码** — 1Password 发布 1Password for Agents 平台，让个人 AI 智能体全程不接触、不存储用户密码或验证码，同时可代表用户登录个人账户；TechCrunch 称该功能在保护私有凭据的同时允许 agent 登录客户个人账户。
- **Uber 向全部 3 万名员工部署 ChatGPT Work** — Uber 正在向超过 30,000 名员工全面推广 ChatGPT Work，从此前较小规模试点扩展为企业级全员部署；OpenAI 称其用于研究、数据分析、创建演示等团队工作。
- **MiniMax Code 桌面端推出 Mini App 长运行应用功能** — MiniMax 在 MiniMax Code 桌面应用（macOS/Windows）本地会话中推出 Mini App，定位为带前端和后端的长运行应用，以插件形式安装并与 Agent 双向调用；它把一次性对话扩展为可长期运行、可被 Agent 调用的本地应用形态。
- **Kling 4.0 上线 OpenArt：支持首中尾帧引导与最多 10 张参考图** — OpenArt 宣布 Kling 4.0 上线，可用首、中、尾帧引导视频，最多使用 10 张参考图，并支持文本或帧生成与视频编辑；All-in-One Reference 用一个模型完成生成和编辑。
- **Replit 发布 Monitoring Agent：可自动修复并部署的“值班智能体”** — Replit 发布 Monitoring Agent，为应用提供相当于自主值班工程师的监控智能体；它可以读取生产日志和指标调查错误、变慢和部署失败，在启用 autofix 后可验证修复并邮件汇报。
- **Spotify 的 AI 赌注：成为智能体主动选择的音乐服务** — Spotify 联合 CEO Gustav Söderström 解释，为何 AI 智能体崛起可能对音乐服务反而是好消息；TechCrunch 称 Spotify 当前 AI 策略是让服务成为 agent 选择的音乐服务。
- **Meta Muse 用户超 1000 万，购物成为热门活动之一** — Meta 在 Q3 财报电话会上称 Muse 用户已超过 1000 万，用户正将其用于购物和个人生产力；TechCrunch 称购物是 Muse 的热门活动之一。

**🛠️ 开源 & 论文**
- **MiniMax 开源 M3.1 Flash 权重：总参数 428B、激活 23B，72 小时处理 Token 超 100 万亿** — MiniMax 开源 M3.1 Flash 模型权重，总参数 428B、激活参数 23B；上线 72 小时内真实用户处理 Token 超过 100 万亿。
- **Anthropic 将 Agent Skills 开放标准捐赠给 Linux Foundation 旗下 AAIF** — Anthropic 宣布把 Agent Skills 开放标准捐赠给 Linux Foundation 旗下的 Agentic AI Foundation（AAIF），此前已向其捐赠 MCP；这推动智能体技能标准中立化与跨生态互操作。
- **Anthropic 指南：何时把子智能体合并进主 Agent 循环** — Anthropic Applied AI 团队发布指南，讲解何时把 orchestrator 下的路由器、规划器和领域子智能体合并进单个主 Agent 循环；文中对比了带 skills 的单智能体与多子智能体架构的取舍。
- **Anthropic 用 Claude 对 123 个开源库完成汇编级形式化安全证明** — Anthropic 与 Theorem 合作，用 Claude 将 OSS-Fuzz 模糊测试转化为规格，对 123 个开源库的 239 个入口点证明任意 64 MB 以下输入不崩溃，生成约 1.8 亿行 Rocq 证明。
- **wesbos/3d-model-anything 登上 GitHub 新星：用 iPhone LiDAR 重建可编辑 Three.js 房间** — 该项目可捕获 iPhone LiDAR 与照片，重建可编辑的 Three.js 房间并在浏览器中探索，获得约 500 星；适合商品/空间 3D 展示、虚拟样板间与快速原型。
