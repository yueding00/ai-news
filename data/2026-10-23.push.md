# AI 日报 · 10月23日 周五

**🔥 头条**
1. **OpenAI 被曝以 1.25 万亿美元目标估值磋商 300 亿美元新融资** — TechCrunch 与 IT之家援引彭博社称，OpenAI 正就约 300 亿美元新融资进行最后阶段磋商，目标估值下调至 1.25 万亿美元。公司同时在推进 IPO 准备。
2. **Anthropic 被曝最快本周五提交 S-1，或创史上最大 IPO** — 雅虎财经援引知情人士称，Anthropic 最早或于本周五公开提交 S-1 招股说明书，推进有望创史上最大规模的 IPO。此前 Newcomer 长文称其风投持股高度分散，目前没有风投机构持股超过 2%。
3. **OpenAI 正式发布 Decisions API：低延迟低成本小决策，最高快 10 倍** — OpenAI 宣布基于 GPT-6 Luna 的 Decisions API 正式可用，用于分类、路由、评分等有界答案问题。官方称其速度最高比通过 Responses API 使用 GPT-6 Luna 快 10 倍，定位低延迟、低成本的小决策。

**🧠 模型 & 产品**
- **MiniMax 开源 M3.1 Flash：428B 总参数、23B 激活，72 小时处理 Token 超 100 万亿** — MiniMax 开源 M3.1 Flash 模型权重，总参数 428B、激活参数 23B，上线 72 小时内真实用户处理 Token 超过 100 万亿。该模型上线 72 小时处理 Token 超 100 万亿，显示高吞吐使用规模。
- **Replit 发布 Monitoring Agent，为应用提供可自动修复的值班智能体** — Replit 发布 Monitoring Agent，为应用提供可自动修复并部署的值班智能体。它可以读取生产日志和指标，调查错误、变慢和部署失败，在启用 autofix 后验证修复并邮件汇报。
- **Claude 网页、桌面和移动端将默认启用 auto mode** — Claude 官方宣布，下周起 Pro、Max 和 Team 套餐在网页、桌面和移动端应用中的会话将默认以 auto mode 运行。auto mode 不再逐步请求用户批准，而由自动检查拦截高风险操作。
- **Microsoft AI 发布 SDBench 与 MAI-DxO 诊断系统，登上 Science** — Microsoft AI 发布 Sequential Diagnosis Benchmark（SDBench）和 AI 诊断系统 MAI-DxO，论文发表于 Science。TechCrunch 称该系统在困难病例上击败全科医生。
- **Canva 发布首个自研图像生成模型，向所有用户开放** — Canva 发布首个自研图像生成模型，向所有用户开放，并承诺更好、更可定制的性能。该模型会先在生成前规划设计方案，再输出图像。
- **Kling 4.0 上线 OpenArt，支持首中尾帧与最多 10 张参考图** — Kling 4.0 上线 OpenArt，支持用首、中、尾帧引导视频，最多使用 10 张参考图。它支持文本或帧生成与视频编辑，All-in-One Reference 用一个模型完成生成和编辑。
- **MiniMax Code 桌面端推出 Mini App 长运行应用** — MiniMax 在 MiniMax Code 桌面应用（macOS / Windows）本地会话中推出 Mini App。这是一种带前端和后端的长运行应用，以插件形式安装并与 Agent 双向调用。
- **1Password 推出 for Agents：AI 可代登录但不接触密码** — 1Password 推出 1Password for Agents 平台，让个人 AI 智能体代用户登录账户。智能体全程不接触、不存储用户的密码或验证码。

**🛠️ 开源 & 论文**

- **Anthropic 用 Claude 对 123 个开源库完成形式化安全证明** — Anthropic 与 Theorem 合作，用 Claude 将 OSS-Fuzz 模糊测试转化为规格。团队对 123 个开源库的 239 个入口点证明任意 64 MB 以下输入不崩溃，生成约 1.8 亿行 Rocq 证明。
- **wesbos/3d-model-anything 登上 GitHub 新星榜：用 iPhone LiDAR 重建 Three.js 房间** — wesbos/3d-model-anything 登上 GitHub 新星榜，获约 500 星。项目可捕获 iPhone LiDAR 与照片，重建可编辑的 Three.js 房间，并在浏览器中探索。
- **skills.sh 热门技能 agent-browser：累计 120 万安装** — vercel-labs/agent-browser 在 skills.sh 累计 120 万安装，是 Agent 浏览器技能。它让 Agent 直接操作网页并完成浏览器任务。
- **skills.sh 热门技能 hyperframes-cli：累计 120 万安装** — heygen-com/hyperframes-cli 在 skills.sh 获 120 万安装，属于 Hyperframes 技能家族。它提供 CLI 方式驱动 Hyperframes 工作流。
- **MiniMax 开源 M3.1 Flash：428B 总参数、23B 激活，72 小时处理超 100 万亿 Token** — MiniMax 开源 M3.1 Flash 模型权重，总参数 428B、激活参数 23B。官方信息称上线 72 小时内真实用户处理 Token 超过 100 万亿，显示高并发推理需求。
- **Microsoft AI 发布 SDBench 与 MAI-DxO 诊断系统，论文登上 Science** — Microsoft AI 发布 Sequential Diagnosis Benchmark（SDBench）与 AI 诊断系统 MAI-DxO，相关论文发表于 Science。该工作用基准评估顺序诊断能力，并以专门系统处理复杂病例诊断。
